# Githio

Red social de práctica sobre programación, videojuegos y proyectos.
Sus publicaciones se llaman Giths.

## Tecnologías

HTML, CSS y JavaScript.
Git y GitHub para el control de versiones.

## Funciones principales

- Registro, inicio y cierre de sesión.
- Publicación de Giths con título, contenido y categoría.
- Filtro por categoría.
- Me gusta y guardados para usuarios con sesión iniciada.
- Eliminación de publicaciones propias.
- Cambio de foto de perfil y avatar en las publicaciones nuevas.
- Adjuntos con un máximo total de 300 MB por Gith.
- Visualización de imágenes y videos compatibles con el navegador.
- Descarga de archivos adjuntos.
- Diseño adaptable a diferentes tamaños de pantalla.

## Cómo probarlo

1. Abrir index.html en el navegador.
2. Crear una cuenta e iniciar sesión.
3. Publicar un Gith y probar sus botones.
4. Cambiar la foto desde Perfil.
5. Cerrar sesión para comprobar las restricciones.

## Limitaciones

Los datos se mantienen únicamente durante la sesión de la página.
Las cuentas, publicaciones, fotos y adjuntos se pierden al recargar.
Los archivos se muestran localmente; no se suben a un servidor.
